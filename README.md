# Praha 8 v přehledech

Veřejná data MČ Praha 8 přehledně na jednom místě.

Projekt zpřístupňuje usnesení, hlasování, rozpočet, organizace, Registr smluv a další veřejné informace s dohledatelným zdrojem dat.

## Provoz

Web je navržen jako statická aplikace. Datové zdroje budou aktualizovány automaticky pomocí GitHub Actions v denním a týdenním režimu; volby a rozpočet budou aktualizovány ručně.

Projekt vytvořil Martin Štěrba v roce 2026.
